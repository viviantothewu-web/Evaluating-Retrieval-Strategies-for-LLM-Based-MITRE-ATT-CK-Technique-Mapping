# Evaluating-Retrieval-Strategies-for-LLM-Based-MITRE-ATT-CK-Technique-Mapping
How does retrieval strategy affect the accuracy of LLM-based mapping of cybersecurity threat descriptions to MITRE ATT&amp;CK techniques?

# Datasets

This project uses:

1. MITRE Enterprise ATT&CK v19.2
   - Source: MITRE ATT&CK STIX Data
   - File: enterprise-attack-19.2.json

2. TRAM ATT&CK Multi-Label Dataset
   - Source: Hugging Face
   - Dataset: ctokx/tram-attack-multilabel-clean
   - Configuration: document

See the data preparation notebooks for download and preprocessing steps.
